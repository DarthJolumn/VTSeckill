## 二、标准答案要点（面试可直接背）

### 1. P99 / P95 / 吞吐量（🔴 必须背熟）

- **定义**：把所有请求的响应时间**从小到大排序**，第 99 / 95 百分位上的那个数值。
- **含义**：P99 = x 毫秒，表示「99% 的请求响应时间 ≤ x 毫秒」。
- **用途**：衡量**长尾延迟**（少数慢请求拖累用户体验），不是"前 99% 的延迟"。
- **吞吐量**：单位时间处理的事务数（QPS=每秒请求数 / TPS=每秒事务数），衡量系统容量。
- 记忆锚点：**排序 → 分位数 → 长尾**。

### 2. Kafka 三大组件 + Broker（🔴）

- **Producer**：生产消息，发到指定 Topic。
- **Consumer**：消费消息，按 Consumer Group 拉取。
- **Broker**：集群中的**一个节点**，负责接收 Producer 消息、**持久化到磁盘**（顺序写 + 副本）、响应 Consumer 拉取——是**存储 + 转发**的核心。
- 一句话：Producer 写、Broker 存、Consumer 读。

### 3. 异步下单：防丢 + 状态感知（🔴）

- **防丢消息**（三端）：Producer `acks=all`（等所有副本落盘）；Broker 副本机制（replication factor）；Consumer 手动提交 offset（消费成功才提交）。
- **用户感知状态**：前端**轮询订单状态接口**，或 **WebSocket 长连接推送**结果（你项目里就是 Redis Pub/Sub + WS 推送）。
- **兜底**：定时任务扫描"处理中"超时订单 / 死信队列处理失败消息 / 幂等（DuplicateKey 兜底）。
- 项目锚点：你的 SeckillOrderConsumer 手动 ACK + 幂等去重 + 内存重试 3 次，正好讲这个。

### 4. 三级缓存标准话术（🟠 背下来形成肌肉记忆）

- **L1 本地缓存 Caffeine**：挡**极热点**（爆款短链），速度最快、无网络开销，但容量小、多节点不一致。
- **L2 分布式缓存 Redis**：**主查询场景**，承载绝大部分流量，全集群共享。
- **L3 数据库 MySQL**：数据**最终源头**，保一致性和持久化；只有缓存全未命中才查 DB 并回写。
- **一致性**：先更新 DB → 删除 Redis → 用 MQ / 延迟双删清理本地 Caffeine。
- 注意发音：**Caffeine**（/'kæfiːn/ 咖啡因），别念成"凯夫瑞"。

### 5. inner join vs left join（🟠）

- **inner join**：取**两表交集**，只保留两边都匹配上的行。
- **left join**：保留**左表全部行**，右表匹配不上的填 `NULL`。
- right join 反之；full join 两边都全。
- 记忆：left join 以左表为主，右表没匹配就补 NULL。

### 6. ArrayList 内存布局（🟠 唤醒即可）

- 本质：**动态数组**，底层 `Object[] elementData`，对象和数组都存**堆**中。
- **懒加载**：JDK8 无参构造 `elementData = {}`，第一次 `add` 时才初始化为**默认容量 10**。
- **扩容**：满时扩容 **1.5 倍**，`Arrays.copyOf` 复制到新数组。
- 你有 HashMap/ArrayList 源码底子，这里只是讲乱了，重新理顺一遍即可。

### 7. HTTP 协议作用（🟡）

- 应用层协议，基于 TCP，**无状态**的**请求-响应**模型。
- 作用：定义客户端与服务器之间**超文本传输**的格式（请求行/头/体 + 方法 GET/POST + 状态码 2xx/3xx/4xx/5xx）。
- 别只答"传输"两个字——落到"请求-响应、无状态、方法+状态码"才算完整。

### 8. 分页查询数据结构（🟡）

- 别直接用裸数组存，用 **List/ArrayList** 包装。
- 实际工程：MyBatis-Plus 的 `Page` 对象 + `PageHelper`，或 SQL `LIMIT offset,size`；返回分页结果对象（记录列表 + total）。
- 项目锚点：你项目里 `PageRequest.of(0, batchSize)` 分页扫描超时订单。

## 四、表达层改进（贯穿，治根因 4）

1. **术语必须读准**：Caffeine、elementData、AQS、G1 等，宁可慢不能谐音。
2. **不会的题先说 30 秒再承认**：禁止直接"不清楚"放弃（面试官要的是思考过程）。
3. **去口语词**：呃/那么/这个 → 换成"首先…其次…综上"。每个回答结尾用一句话收束（"回答完毕"）。
4. **三段式**：结论 → 机制 → 例子，每次口述都套这个模板。
